# OUTCOME_PREREGISTRATION — Phase 3B 사전등록

작성: 2026-09-16, **결과 관측 전**. 배포 후 28일이 지나기 전에는 결과를 계산하지 않는다.

## 1. 설계

- 단위: 기존 스포크 페이지 40개 (처치 20 / 대조 20)
- 배정: 사전 처치 변수로 만든 **20개 매칭 페어 안에서 무작위 배정** (seed `LG_GROWTH_3B_20260916`)
- 처치: 표준화된 리프레시 묶음(H1 질문형 전환 · 판단표 1개 · 검증된 공식 출처 링크 2~3개 · 검증된 사실 정정 · 관련 기존 페이지 3곳에서 문맥 내부링크)
- 대조: 내용·메타데이터 무변경. 전역 3B-0 기술 수정(구조화 데이터 날짜 정직화, /diagnosis 계측)만 동일하게 적용

## 2. 주 결과 (primary)

**페이지별 Naver-origin 세션**, sourceMedium ∈ {`m.search.naver.com / referral`, `naver / organic`}

- 사전 기간(동결): 2026-08-19 ~ 2026-09-15 (`ga4_naver_frozen_input.csv`)
- 사후 기간: EXPERIMENT_START(프로덕션 배포 시각) 다음 날부터 **28일 연속**
- 결과 변수: `Y = log(1 + 세션)`
- 추정: 페어별 이중차분 `D_p = (Y_post − Y_pre)_treat − (Y_post − Y_pre)_control`
- 검정: **무작위화 추론(permutation)** — 페어 내 배정 뒤집기 2^20 조합 중 20,000회 몬테카를로 샘플로 귀무분포 생성, 양측 p값
- 보고 항목(전부):
  - 처치/대조의 사전·사후 **원시 평균과 중앙값**
  - 원시 퍼센트 변화
  - 페어별 차이 20개 전부
  - log 효과와 그 역변환 근사치(%)
  - permutation p값과 불확실성 구간

## 3. 부 결과 (secondary, 탐색적)

- 활성 사용자 수
- 참여/이탈 지표
- `situation_start`, `situation_complete`, 시작 대비 완료율
- `chat_start`, `chat_complete`

> **한계**: `/diagnosis` 계측은 이번 배포로 처음 생겼다. 사전 기간 동등 지표가 없으므로 전환 지표는 **사후 탐색적**으로만 해석하고, 인과 주장에 쓰지 않는다.

Google 색인/GSC 변화는 기록만 하고 **주 결과로 쓰지 않는다**.

## 4. 판정 규칙

- **자동 롤아웃 규칙 없음.** "+20% 확대 / +10% 중단" 같은 임계값은 쓰지 않는다.
- 처치군이 올랐다는 사실만으로 성공이라고 하지 않는다. **대조군도 같이 오를 수 있으므로** 반드시 DiD + permutation 으로 본다.
- 결과 해석 시 함께 보고할 것:
  - 대조군 자체의 변화(시장·계절·Naver 로테이션의 크기)
  - 페어별 이질성(효과가 특정 도메인에만 몰렸는지)
  - 처치 미전달(`treatment_not_delivered=1`) 페이지 포함 여부 — **주 분석은 ITT(배정대로)** 로 하고, 보조로 실제 전달분만 본 분석을 따로 보고

## 5. 알려진 교란 요인 (미리 기록)

1. **`dateModified` 동반 개입** — 처치군만 수정일이 2026-09-16 으로 갱신된다(ARTICLE_DATE_AUDIT.md §4). "내용 개선"과 "신선도 신호"를 분리할 수 없다.
2. **문맥 내부링크** — 처치 묶음에 포함돼 있어, 콘텐츠 개선 효과와 링크 효과가 섞인다(묶음 전체의 효과만 추정 가능).
3. **도너 페이지** — 도너는 대조군이 아니지만 3B 외 페이지다. 도너 쪽 트래픽 변화는 분석 대상이 아니다.
4. **표본 규모** — 20페어. 작은 효과는 검출되지 않을 수 있다. p값이 크다고 "효과 없음"으로 단정하지 않는다.
5. **Naver 로테이션** — Phase 3A 에서 관찰된 순위 변동이 크므로, 대조군 분산이 넓을 수 있다.

## 6. 실험 기간 중 금지 사항

처치·대조 40개 페이지에 대해:
- 추가 리라이트, 제목/메타 실험, CTA 실험, 병합·삭제·noindex, 추가 내부링크 캠페인, Naver 수동 수집요청 실험 참여 **금지**
- 불가피한 법률 오류 정정이 필요하면 **수정하고 `contamination_log.csv` 에 기록**한다(숨기지 않는다)

사이트의 다른 영역 운영은 계속해도 된다.
